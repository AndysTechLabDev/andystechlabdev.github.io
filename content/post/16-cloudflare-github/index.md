## Overview
Learn how to connect a custom domain to your Hugo blog hosted on GitHub Pages and manage your DNS using Cloudflare's free plan.

In this tutorial, we'll take the Hugo site we previously deployed with GitHub Pages and replace the default github.io URL with our own custom domain.

We'll set up the domain in Cloudflare, configure the required DNS records, enable Cloudflare's proxy, and connect everything to GitHub Pages.

For my domain registrar I'm using Porkbun, but you can use any registrar you prefer.
