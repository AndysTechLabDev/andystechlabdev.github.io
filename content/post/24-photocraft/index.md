## Overview

Photoshop is the application that still keeps me using Windows. So when I came across PhotoCraft, a free, open-source image editor with native Linux support, I wanted to see what it could do.

And yes, I know GIMP exists. I’ve tried it, but I’ve never quite felt comfortable with its workflow. Another option with a familiar interface is something I’m happy to explore.
___
## What is PhotoCraft?

PhotoCraft is an image editor from the ArtCraft team, built in Rust and available for Linux, Windows, and macOS.

It offers familiar tools such as layers, masks, editable text, adjustments, and layer effects. It also supports opening and saving layered PSD files, although compatibility should be tested with your own projects.

AI coding agents are part of its development process. The project is still in alpha, so its feature list shouldn’t be mistaken for complete Photoshop compatibility or professional readiness.
