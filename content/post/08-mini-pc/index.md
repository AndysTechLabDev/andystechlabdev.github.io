## Overview
I bought a used mini PC for just 40€ and turned it into a fully functional home server using Docker. 

In this video, I’ll show you how I replaced multiple Raspberry Pis and improved my entire home network setup.

## Setup
- Ubuntu Server installation
- Docker & Docker Compose setup
- ddclient for dynamic DNS
- Pi-hole for network-wide ad blocking
- Nginx Proxy Manager for local DNS and reverse proxy
- Homebridge for Apple HomeKit integration

This setup allows me to run a clean, stable, and efficient home lab on cheap hardware.
