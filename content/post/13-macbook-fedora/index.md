## Overview
After years of running Linux servers, I finally decided to give Linux as a desktop operating system a real chance.

In this video, I install Fedora KDE Plasma on my 2017 MacBook Air and start my journey into the Linux desktop world. My goal is to customize the system, install essential applications, and see if Linux can become my daily driver.

I begin by showing the MacBook Air running Fedora KDE Plasma before diving into my very first desktop experience. Throughout the video, I create a task list of everything I want to improve—from visual customization to installing the software I need for everyday use.

Whether you're new to Linux, considering Fedora KDE Plasma, or curious about running Linux on older Apple hardware, follow along as I explore the desktop ecosystem for the first time.
